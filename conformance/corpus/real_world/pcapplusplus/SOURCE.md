# PcapPlusPlus test captures

Every `.pcapng` and `.zst` file in [PcapPlusPlus](https://github.com/seladb/PcapPlusPlus) at commit `ca939a2f11d76df01414a4534bcc55df46507c42`. Each one keeps its path in that repository, so a file can be traced back to the PcapPlusPlus test that uses it.

To refresh from a newer commit, replace this directory with the same files from that commit, update the hash above, and regenerate the goldens.
